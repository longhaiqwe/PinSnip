# PinSnip

PinSnip 是一款原生 macOS 截图、滚动截屏、录制动图与贴图工具。

- `F1`：截图
- 菜单栏「滚动截屏…」：生成长截图（[使用指南](docs/features/scrolling-capture.md)）
- `F3`：框选区域并录制 GIF
- `F4`：从新到旧逐张贴出最近 10 张截图；新复制的图片优先贴出，剪贴板文字会被忽略，不再生成文字或颜色卡片

菜单栏「图片样式」可选择七种渐变背景、渐变 · 自动配色或原图，并会全局记住上次选择。普通截图、滚动长图、录制动图和截图贴图都会使用同一种样式。
渐变背景包括暮色、海蓝、薰衣草、蜜桃、薄荷、玫瑰和石墨，默认使用暮色。旧版剪纸设置会自动改用暮色；「自动配色」从截图中选取主要色系，按画面明暗生成柔和渐变；黑白截图使用中性灰，动图沿用首帧配色。
「图片样式」中的「边框大小」支持自动、24 / 48 / 80 / 120 像素和 8–300 像素自定义宽度，按导出图片每侧的像素计算并自动记住，适用于自动配色和所有固定渐变背景，原图不受影响。
滚动截屏或动图录制期间，开始导出前可按 `Esc` 取消并退出。点击「复制」会结束采集并把结果写入剪贴板。
复制 GIF 时（包括从晾衣架复制），按菜单栏「设置 → GIF 分享大小…」中的设置压缩；默认限制为 1280 × 1080 像素、15 MB。必要时降低尺寸或帧率，保留完整播放时长、最后一帧与循环设置。复制和拖拽均提供完整 GIF 数据、Qt 的 GIF MIME 表示及文件地址，供接收应用选择；晾衣架原文件及保存、拖出导出的 GIF 保留原始尺寸。详情与聊天软件兼容边界见 [GIF 分享说明](docs/gif-sharing.md)。

普通截图支持矩形、箭头、画笔、文字、序号和马赛克标注。箭头可选择线条、实心或空心样式。画笔可直接选择蓝、绿、黄、深灰、白、红六种颜色，换色只影响后续笔画。文字可选择字号与颜色，并可拖动移动或调节宽度来控制换行。序号支持小、中、大、特大四档大小；选择序号工具后可设置大小，点击已有序号可重新调整，支持撤销与重做。
添加文字时，首行以点击位置为垂直中心并向右输入。编辑时拖动文字框边框移动，拖动左右控制点调宽；
已完成的文字可直接拖动，双击重新编辑。输入时回车换行，`⌘ Enter` 完成文字编辑。

菜单栏「设置」中的「晾衣架位置」可选择屏幕上方、下方、左侧或右侧，默认上方，选择后立即生效并自动保存。鼠标在对应屏幕边缘停留约 0.25 秒即可展开，离开后自动收起；顶部直接移到屏幕最上沿即可，无需再向下挪。上方和下方停靠时，左右各留 160 点空隙，小尺寸屏幕按比例缩小；两端空隙不会触发展开。左右两侧纵向排列，截图较多时可在卡片上滚动浏览；也可用「暂存晾衣架」手动展开或收起。
卡片按缩略图实际尺寸紧凑排列：左右侧根据高度、上下侧根据宽度计算位置，图片之间保留一致留白，短图或窄图不再占用固定长度的槽位。
拖动单张截图到晾衣架内的插入标记处即可调整顺序：上下位置左右排序，左右位置上下排序；靠近面板两端会自动滚动。拖出晾衣架仍可导出到访达或其他应用，取消拖动不改变顺序。

截图与动图保存在 `~/Library/Application Support/PinSnip/Shelf/`，与应用安装目录分开。退出、重启或替换新版后，会自动恢复本地截图与已保存的排列顺序；旧版留下但未显示的截图也会自动载入。截图数量不再触发自动删除，较长的队列可滚动浏览。

晾衣架下方的「一键清理」可取下全部截图和 GIF，原文件会归档。点击「撤销取下」可按原顺序恢复刚取下的卡片。更早归档的文件可从菜单栏「截图与贴图管理 → 恢复已取下的截图」恢复。归档失败的卡片继续保留。

菜单栏「截图与贴图管理 → 打开本地截图文件夹」可查看原文件。从晾衣架取下或转为桌面贴图时，原文件移入该目录的 `Archive` 子目录，可通过「恢复已取下的截图」重新挂回。拖到访达并执行移动的文件仍在所选目标文件夹中。此前旧版已永久删除、且本地没有副本的文件无法通过这项恢复功能找回。

可在菜单栏「设置 → 快捷键设置…」修改快捷键。截图、滚动拼接、动图和贴图均在本机处理。

菜单栏「设置 → 开机启动」可设置登录后自动运行 PinSnip；需要系统批准时会提示前往「登录项与扩展」。

菜单栏底部显示当前版本。「更新」子菜单支持手动检查更新，也可以分别关闭自动检查、自动下载并安装更新。PinSnip
仅在检查或下载更新时访问 GitHub 上的更新清单与 Release 安装包；截图、滚动拼接、
动图和贴图仍完全在本机处理，不包含遥测或用户账户。

## 下载

从 [最新版本下载页](https://github.com/longhaiqwe/PinSnip/releases/latest) 下载 `.dmg` 安装包，打开后将 PinSnip 拖入「应用程序」文件夹，再从「应用程序」启动。支持 macOS 14 及以上系统，兼容 Apple 芯片和 Intel 芯片。也提供 ZIP 解压安装包。

首次使用时可能需要以下权限：

- **屏幕与系统音频录制**：截图、滚动截屏和 GIF 录制所必需。
- **辅助功能**：仅用于自动滚动；未授权时滚动截屏仍可使用，但会切换为手动模式。

## 构建

需要 Xcode 26 和 [XcodeGen](https://github.com/yonaskolb/XcodeGen)。

```bash
./scripts/build-release.sh
```

脚本会运行测试，并在 `build/Release` 中生成同时支持 `arm64` 与 `x86_64` 的 `PinSnip.app`。

发布新版本及生成签名更新清单的步骤见
[发布与自动更新](docs/releasing.md)。
本机替换已安装版本也必须沿用原来的正式 Developer ID 签名，具体要求见 [项目约定](AGENTS.md)。
正式签名构建完成后，使用 `./scripts/install-release.sh` 校验并替换安装；
使用 `./scripts/install-release.sh --check` 可只读预检，身份不兼容时脚本会拒绝替换。
