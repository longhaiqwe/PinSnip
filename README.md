# PinSnip

PinSnip 是一款原生 macOS 截图、滚动截屏、录制动图与贴图工具。

- `F1`：截图
- 菜单栏「滚动截屏…」：生成长截图（[使用指南](docs/features/scrolling-capture.md)）
- `F3`：框选区域并录制 GIF
- `F4`：从新到旧逐张贴出最近 10 张截图；新复制的图片优先贴出，剪贴板文字会被忽略，不再生成文字或颜色卡片

菜单栏「图片样式」可选择剪纸、边框 · 随机适配、边框 · 暮色渐变（固定）或原图，并会全局记住上次选择。普通截图、滚动长图、录制动图和截图贴图都会使用同一种样式。
「暮色渐变」使用深蓝、暖橙与酒红的固定渐变背景；「随机适配」保留根据截图内容自动配色的效果。
「图片样式 → 边框大小」支持自动、24 / 48 / 80 / 120 像素和 8–300 像素自定义宽度，按导出图片每侧的像素计算并自动记住，仅影响两种边框样式。
滚动截屏或动图录制期间，可以随时按 `Esc` 取消并退出。

普通截图支持矩形、箭头、画笔、文字、序号和马赛克标注。箭头可选择线条、实心或空心样式。文字可选择字号与颜色，并可拖动移动或调节宽度来控制换行。序号支持小、中、大、特大四档大小；选择序号工具后可设置大小，点击已有序号可重新调整，支持撤销与重做。
添加文字时，首行以点击位置为垂直中心并向右输入。编辑时拖动文字框边框移动，拖动左右控制点调宽；
已完成的文字可直接拖动，双击重新编辑。输入时回车换行，`⌘ Enter` 完成文字编辑。

菜单栏「晾衣架位置」可选择屏幕上方、下方、左侧或右侧，默认上方，选择后立即生效并自动保存。鼠标在对应屏幕边缘停留片刻即可展开，离开后自动收起。左右两侧纵向排列，截图较多时可在卡片上滚动浏览；也可用「暂存晾衣架」手动展开或收起。
拖动单张截图到晾衣架内的插入标记处即可调整顺序：上下位置左右排序，左右位置上下排序；靠近面板两端会自动滚动。拖出晾衣架仍可导出到访达或其他应用，取消拖动不改变顺序。

快捷键可以在菜单栏中修改。截图、滚动拼接、动图和贴图均在本机处理。

菜单栏「开机启动」可设置登录后自动运行 PinSnip；需要系统批准时会提示前往「登录项与扩展」。

菜单栏支持“检查更新…”，也可以分别关闭自动检查、自动下载并安装更新。PinSnip
仅在检查或下载更新时访问 GitHub 上的更新清单与 Release 安装包；截图、滚动拼接、
动图和贴图仍完全在本机处理，不包含遥测或用户账户。

## 下载

从 [最新版本下载页](https://github.com/longhaiqwe/PinSnip/releases/latest) 下载 `.dmg` 安装包，打开后将 PinSnip 拖入「应用程序」文件夹，再从「应用程序」启动。支持 macOS 14 及以上系统，兼容 Apple 芯片和 Intel 芯片。也提供 ZIP 解压安装包。

首次使用时可能需要以下权限：

- **屏幕与系统音频录制**：截图、滚动截屏和 GIF 录制所必需。
- **辅助功能**：仅用于自动滚动；未授权时滚动截屏仍可使用，但会切换为手动模式。

## 构建

需要 Xcode 26 和 [XcodeGen](https://github.com/yonaskolb/XcodeGen)。

```bash
./scripts/build-release.sh
```

脚本会运行测试，并在 `build/Release` 中生成同时支持 `arm64` 与 `x86_64` 的 `PinSnip.app`。

发布新版本及生成签名更新清单的步骤见
[发布与自动更新](docs/releasing.md)。
本机替换已安装版本也必须沿用原来的正式 Developer ID 签名，具体要求见 [项目约定](AGENTS.md)。
正式签名构建完成后，使用 `./scripts/install-release.sh` 校验并替换安装；
使用 `./scripts/install-release.sh --check` 可只读预检，身份不兼容时脚本会拒绝替换。
