## 验证方法

- 直接实例化实际 `SelectionOverlayView` / `TextAnnotationEditorView`，用合成截图背景执行原生布局并导出图片；不是 HTML 或设计稿模拟。
- 检查 1280、600、375 点宽度的空文字/已输入文字状态。预览位于忽略目录 `build/previews/ui-*-*.png`。
- 行为测试检查屏幕上中下位置的所有可见按钮均在边界内，文字面板与工具栏不相交；检查勾选唯一、撤销/重做和导出结果。
- 修复初始化时零尺寸 StackView 带来的约束冲突；验证日志中无布局冲突。
- 继续由 `scripts/install-release.sh` 强制验证正式签名及新旧身份，身份不符不得安装。
