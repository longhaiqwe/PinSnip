# PinSnip v0.9.2

发布日期：2026-10-23

## 改进与修复

- 复制 GIF 时自动按比例缩小超大动图，宽度不超过 1280、高度不超过 1080 像素，改善直接粘贴到 X 等平台时的尺寸兼容性。录制完成后的复制与晾衣架复制均支持。
- 缩放保留动画帧、每帧时长和循环设置；晾衣架原文件、保存及拖出导出的 GIF 继续保留原始清晰度。
- 每次复制使用独立的临时文件，避免后续复制覆盖浏览器仍在读取的动图。
- 优化 GIF 录制的无损帧缓存：按画面内容选择压缩或原始像素存储，并连续写入单个缓存文件，减少无效压缩和频繁创建文件的开销。
- 补充缓存回读与动图缩放回归测试，并修正菜单快捷键测试的等待条件。

## 下载与安装

推荐下载 **PinSnip-v0.9.2-macOS-universal.dmg**，打开后将 **PinSnip** 拖入 **应用程序** 文件夹。

- 支持 **macOS 14 及以上**，同一个安装包兼容 **Apple 芯片和 Intel 芯片**。
- 安装包沿用 Developer ID 正式签名，并通过 Apple 公证。
- ZIP 用于手动解压安装及应用内自动更新；`.sha256` 文件用于核验下载文件完整性。
- 已安装用户可以从菜单栏选择 **检查更新…** 获取新版。
