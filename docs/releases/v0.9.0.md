# PinSnip v0.9.0

发布日期：2026-10-21

## 新功能

- 新增截图与 GIF 暂存晾衣架，支持屏幕四边停靠、边缘悬停展开、拖动排序、滚动浏览及拖出导出。
- 新增开机启动开关，可从菜单栏设置登录后自动运行。
- 箭头标注支持线条、实心和空心三种样式；序号标注支持四档大小，并可调整已有序号。
- 图片边框新增固定暮色渐变，支持预设和 8–300 像素自定义宽度。

## 改进与修复

- 改善文字标注的点击定位、拖动、宽度调整和再次编辑，支持多行输入与 ⌘ Enter 完成编辑。
- 优化截图工具栏分组、窄屏布局、选中反馈及撤销/重做状态，统一操作按钮的图文居中显示。
- 改善菜单展开时的快捷键截图和 GIF 选区操作，保留截图中的菜单内容。
- GIF 录制仅排除录制控制窗口，可录入贴图和晾衣架；改善取消处理和晾衣架 GIF 预览。
- 改善滚动长图的重叠匹配与固定底栏拼接；匹配失败时尝试回退恢复，无法自动滚动时提示手动滚动。
- 增加正式签名安装保护脚本，校验新旧应用身份兼容性并在替换前备份。

## 下载

推荐下载 `PinSnip-v0.9.0-macOS-universal.dmg` 安装；同时支持 Apple 芯片和 Intel 芯片，要求 macOS 14 或更高版本。ZIP 用于手动解压安装及应用内自动更新。
