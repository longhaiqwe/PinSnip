# PinSnip v0.9.4

## 晾衣架

- 修复「一键清理」显示后点不到的问题。清理后可点「撤销取下」，按原顺序恢复本次取下的卡片。
- 撤销时复用已有缩略图，批量恢复时不用逐张重新生成。滚出可视区的动图会暂停播放。
- 空晾衣架可以直接开始截图。卡片支持键盘和读屏操作。双击贴图不会先改写剪贴板。

## 截图、长图与动图

- 普通截图和长图在打开保存窗口前会先暂存。取消保存后，已暂存的图片仍可在晾衣架找回。
- 滚动截屏中断时保留已拼接的部分，并提示已截取的屏数。修复导出过程中启动新采集可能导致新面板消失的问题。
- GIF 导出失败后可重试复制或另存为。从桌面贴图复制或保存 GIF 时保留动画。
- 矩形标注支持删除、撤销和重做。录制与长图面板用「复制」说明按钮会把结果放入剪贴板。

## 菜单与设置

- 截图、录制、贴图和晾衣架入口留在首层。管理、设置与更新各有子菜单，菜单底部显示当前版本。
- 快捷键录入时暂停全局操作，冲突会指出具体动作。GIF 设置会指出填错的字段，设置窗口在应用本次运行中记住位置。
- 贴图菜单显示当前不透明度、镜像和置顶状态。启用鼠标穿透时会提示如何恢复操作。

## 下载与安装

推荐下载 **PinSnip-v0.9.4-macOS-universal.dmg**，打开后将 PinSnip 拖入「应用程序」。支持 macOS 14 及以上，兼容 Apple 芯片和 Intel 芯片。已安装用户也可以在菜单栏选择「更新 → 检查更新…」。
