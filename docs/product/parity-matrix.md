# PinSnip macOS 功能对标矩阵

> 基线：Snipaste Desktop 2.11.3（2026-01-18）。PinSnip 是独立实现，不使用 Snipaste 的商标、图标、素材或私有代码。

状态核对日期：2026-11-13（北京时间）。以下按当前工作区代码记录，包含尚未发布的改动。「已实现」表示已有代码及使用入口，不代表本次已完成界面实测或发布验收。阶段编号保留原交付计划，不代表当前完成顺序。

## 产品边界

- 原生 macOS 菜单栏应用，最低支持 macOS 14，Apple Silicon 与 Intel 通用构建。
- 截图、GIF 录制、图片处理和历史记录在本机完成；OCR（图片文字识别）与二维码识别仍在规划中，计划采用本地处理。
- 截图、GIF 录制与贴图默认使用 F1/F3/F4，可在菜单栏「设置 → 快捷键设置…」修改并保存。贴图优先使用新复制的图片，否则逐张贴出最近截图。
- 每个阶段都必须提供可安装版本，并能重复测试已有功能。

## 分阶段交付

1. **基础截图与贴图**：菜单栏、热键、全屏快照、拖选、基础标注、复制/保存/贴图、剪贴板贴图常用变换。
2. **专业截图**：窗口/元素检测、多屏、历史、刷新、固定尺寸/比例、圆角与阴影。
3. **专业标注与识别**：完整标注工具、二次编辑、Vision OCR 与条码识别。
4. **贴图工作区**：分组、多选、Solo、裁剪、动画图、备份恢复。
5. **效率自动化**：白板、触发角、任意快捷键、黑名单、命令行协议。
6. **发行质量**：偏好设置全覆盖、辅助功能、性能、签名公证、更新与迁移。

## 阶段 1 验收标准

- 菜单栏可触发截图、滚动截屏、GIF 录制和贴图；默认 F1/F3/F4，可配置的全局快捷键在其他应用前台时有效。
- 首次截图能正确解释屏幕录制权限，并在授权后抓取当前显示器。
- 拖动形成选区；工具栏可切换矩形、箭头、画笔、文字、序号、矩形马赛克和画笔马赛克；支持撤销/重做。
- 选区可复制 PNG、保存 PNG 或立即成为无标题栏置顶贴图。
- 剪贴板里的图像与图片文件能成为贴图；文字与颜色文本被忽略，不占用截图历史贴图的按键次数。
- 贴图支持拖动、缩放、旋转、镜像、透明度、鼠标穿透和置顶切换。
- 核心几何、命令状态、剪贴板分类与贴图变换有自动化测试。
